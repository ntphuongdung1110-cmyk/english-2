## 📱 Mở như một app trên điện thoại

- **iPhone (Safari):** mở link → nút Chia sẻ ⬆️ → **Thêm vào màn hình chính**
- **Android (Chrome):** menu ⋮ → **Thêm vào màn hình chính**

Sau đó chạm icon là vào thẳng, full màn hình.

## ✨ Tính năng

**🎯 Chương trình học mỗi ngày**
- Lịch học sáng (chủ động) / tối (nhẹ nhàng), kỹ thuật shadowing
- 28 chủ đề hội thoại đời thường, mỗi chủ đề 8 câu hỏi-đáp mẫu (Anh + Việt)
- Đếm chuỗi ngày, link nghe (YouTube, Everyday Conversations)

**📚 Từ vựng — Thêm & Ôn tập**
- Thêm từ/cụm từ có **kiểm tra nghĩa** (Free Dictionary + Wiktionary), gợi ý sửa chính tả
- Sổ từ vựng **nhóm theo 33 chủ đề**, tự phân loại, lọc theo chủ đề
- Ôn bằng **thẻ ghi nhớ** (thuộc/chưa thuộc), đọc to, xuất Anki
- Sẵn ~800 từ vựng theo chủ đề

## ⚙️ Kỹ thuật

Web tĩnh (HTML/CSS/JS thuần), lưu tiến độ bằng `localStorage` trên trình duyệt, host bằng GitHub Pages. Dữ liệu học lưu **riêng theo từng thiết bị/trình duyệt**.
